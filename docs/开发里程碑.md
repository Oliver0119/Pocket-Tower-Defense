# 开发里程碑（按 10~15 小时/周规划，共 8 周）

> 节奏：工作日 1~2 晚（每次 1~1.5h）+ 周末半天（3~4h）。里程碑允许 ±1 周浮动，软著必须第 1 周提交。

## Week 1 — 启动 + 学习
- [ ] 注册微信小游戏账号（个人主体，类目：休闲益智）
- [ ] **提交软著申请**（源码模板可先用 Cocos 示例项目，最长前置！）
- [ ] 安装 Cocos Creator 3.x + 微信开发者工具，跑通官方 Demo → 微信预览全流程
- 产出：可真机预览的空项目

## Week 2 — 战斗核心
- [ ] 战斗场景搭建：地图/出怪路径/摆放点
- [ ] 敌人移动 + 3 种基础塔攻击逻辑（单体/减速/重击）
- [ ] 对象池（敌人/子弹）
- 产出：能打的最小战斗循环

## Week 3 — 循环闭环
- [ ] 波次控制器 + 敌人血量曲线 + 金币掉落经济
- [ ] 塔升级（3 级）+ 建造/卖塔交互
- [ ] 胜负判定 + 结算面板
- 产出：1 个可完整通关的关卡

## Week 4 — 内容与成长
- [ ] Roguelike 三选一技能系统（波次间）
- [ ] 关卡配置表（20 关数据驱动）+ 关卡选择页
- [ ] 存档（本地 storage）
- 产出：完整可玩 MVP（占位美术）

## Week 5 — 平台接入
- [ ] AdService：激励视频 ×3 点位 + 插屏（冷却/次数限制）
- [ ] 游戏圈组件接入 + 发 5 篇官方帖 → 走流量主条件②
- [ ] 真机测试广告（isEnded 判断、重复注册 Bug 排查）
- [ ] 体验版发布
- 产出：接好广告的体验版

## Week 6 — 种子用户 + 调优
- [ ] 邀请 20~50 个种子用户（朋友圈/同事，别说是自己做的）
- [ ] 观察次留/关卡流失点，调数值曲线与广告点位
- 产出：次留 ≥ 20% 的版本

## Week 7 — 上架冲刺
- [ ] 首包体积优化（≤ 4MB）+ 性能真机验证
- [ ] 美术最终替换（AI 生成 + 统一风格）
- [ ] 提交审核（软著需已到位）
- 产出：过审

## Week 8 — 发布
- [ ] 完成备案流程 → 正式发布
- [ ] 种子放量 → 盯自然推流数据
- [ ] 复盘会：决定矩阵第二作的题材与玩法
- 产出：正式上线第一款小游戏 🚀
